# Day 01 - Get Started with Code

You start with obtaining a text editor:

1. Download [VS Code](https://code.visualstudio.com/) to your computer.
2. Launch it. Ignore any offers to install LLMs or AI or Agents, as you are
   trying to learn to code yourself.
3. BUT, if it offers to help you install [Git](https://git-scm.com/), take it up
   on that offer. Otherwise you can install it from the linked website.
4. It should display a welcome screen, "Visual Studio Code - Editing Evolved"
   and under a menu called "Start" there is a link you can click, "Clone Git
   Repository".
5. Copy-paste this repo's URL, `https://github.com/crdrost/oware-learning.git`
   into that text-box.
